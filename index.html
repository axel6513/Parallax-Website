什麼是視差滾動？

就像你坐雲霄飛車時，前面的朋友尖叫得比你大聲，背景動得比較慢，前景動得比較快，這就是視差。 把它搬到網頁上，就能營造出 3D 深度感，讓人以為自己在滑手機時順便鍛鍊核心肌群。

科學小常識：人眼覺得近的東西比較大、跑得比較快，所以遠方的山就像周末的計畫，一直慢吞吞。視差就是拿這個 錯覺來玩。以前動畫師用它，超級瑪利歐也愛用，現在換到網頁上，我們終於可以在家不動也感受「身歷其境」。

順帶一提，2007 年有人在部落格寫了視差效果的 JS + CSS 教學，當時還要兼容 IE6（請為他點一根蠟燭）。 到了 HTML5 / CSS3 時代，設計師才大喊：哇，這個好炫！於是人人都用，但請記得：酷炫不能當晚餐，還是要照顧 使用者的感受。


為什麼要用視差效果？

    兩個理由：讓故事更好笑，讓使用者更捨不得離開。

  • 它能講故事（還能加梗）

    視差很適合說故事。設計的本質是溝通，順便塞幾個笑話，讓訪客一邊滑一邊想： 「這網站是不是在跟我聊天？」一頁到底也能講完整個品牌故事，甚至偷塞彩蛋，讓人忍不住一直往下滑。

  • 它能黏住觀眾（比奶茶還黏）

    做網站最怕「點進來秒走人」。好看的視差就像一杯半糖珍奶，讓人願意多待幾秒， 甚至分享給朋友：嘿，這頁會動耶！你說這算不算口碑行銷？


想自己做視差？這裡有三個偷吃步

  • 小量使用，像辣椒一樣

    辣椒放太多會爆汗，視差放太多會爆眼。挑重點放在首頁或標題區就好， 讓效果成為亮點，而不是讓使用者迷路。

  • 圖片要瘦身，不然大家等到睡著

    視差常用到一堆圖片，記得壓縮，不然讀取時間長到你可以泡杯咖啡回來才看到動畫。

  • 玩玩顏色，讓前景更跳

    視差不只前後景，顏色也很重要。背景走低飽和、前景用亮色，就像在舞台上打 spotlight， 深度感立刻升級。
